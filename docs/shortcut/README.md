# レシピ取り込み用ショートカットの作り方

Safari で開いたレシピのページから、**料理名・材料と分量・調理時間・何人分・URL** だけを取り出してコピーし、
みっかごはんに貼り付けるためのショートカットです。作り方の文章は取り出しません。
外部への通信はしません(iPhone の中だけで動きます)。

> iOS のバージョンによって、ボタンや項目の名前が少し違うことがあります。似た名前のものを選んでください。

---

## 1. スクリプトの実行を許可する(最初の1回だけ)

1. iPhone の「設定」を開く
2. 「アプリ」→「ショートカット」→「詳細」を押す(古い iOS では「設定」→「ショートカット」→「詳細」)
3. 「スクリプトの実行を許可」をオンにする

## 2. ショートカットを作る

1. 「ショートカット」アプリを開き、下の「ショートカット」タブを選ぶ
2. 右上の「＋」を押す
3. 画面上の「新規ショートカット」の名前を押して「名称変更」→「献立に取り込む」と入れる
4. 画面下の「ⓘ」(詳細)を押し、「共有シートに表示」をオンにして「完了」
5. 画面の上に「共有シートから **任意** の入力を受け取る」のような行が出るので、「任意」の部分を押し、
   「Safari Webページ」だけにチェックを残して、ほかは外す
6. 下の検索欄(「アクションを検索」)に「JavaScript」と入れ、「**Webページで JavaScript を実行**」を押して追加する
   - 追加したアクションの「Webページ」の部分が「ショートカットの入力」になっていることを確かめる
7. アクションの中の文字(最初から入っている見本のスクリプト)をすべて消し、
   [`kondate-import.js`](kondate-import.js) の中身をまるごと貼り付ける
   - iPhone でコピーするには、Safari で次のページを開き、文字を長押し →「すべてを選択」→「コピー」
     `https://raw.githubusercontent.com/Creative-Hues/kondate/main/docs/shortcut/kondate-import.js`
   - 最初の行「// みっかごはん:…」から、最後の行「})();」までがすべて入っていることを確かめる
8. 検索欄に「クリップボード」と入れ、「**クリップボードにコピー**」を追加する
   (中身が「JavaScript の結果」になっていることを確かめる)
9. 検索欄に「通知」と入れ、「**通知を表示**」を追加し、文字を
   「みっかごはんを開いて『URLから取り込み』を押してください」に変える
   (前に作ったショートカットは、通知の文字が古いままでもそのまま使えます)
10. 右上の「完了」を押して保存する

## 3. 使い方

1. Safari でレシピのページを開く
2. 画面下の共有ボタン(□に↑)を押し、一覧から「献立に取り込む」を押す
3. 初めてのサイトでは「〜へのアクセスを許可しますか?」と聞かれるので、「常に許可」を押す
4. 通知が出たら、ホーム画面からみっかごはんを開く
5. 「レシピ」タブ →「URLから取り込み」→ 入力欄を長押しして「ペースト」→「読み取る」
6. 確認画面で、区分・難易度・主な材料・調理法・味付けを選び、材料を確かめて「保存」

### アプリを自動で開かない理由

ホーム画面に置いたアプリと Safari は、データの置き場所が別々です。
ショートカットから URL でアプリを開くと Safari 側で開いてしまい、ホーム画面のアプリのレシピに入らないため、
コピーまでをショートカットで行い、アプリは手で開きます。

## うまくいかないとき

- **共有の一覧に「献立に取り込む」が出ない**:共有の一覧を右端までスクロールし「その他」から探す。手順2の4・5を確かめる
- **「スクリプトの実行が許可されていません」と出る**:手順1をやり直す
- **確認画面で材料が読めていない**:構造化データのないページでは、ページの文字から「材料」の見出しから「作り方」の手前までと、時間・人数の行だけを取り出して読むので、読み間違いが増えます。
  確認画面で直してください(直した材料名は次から自動で読めます)
